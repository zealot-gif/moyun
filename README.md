# 墨韻活字工坊 — 110 階正體造字進化遊戲

一套完整拆分為 `HTML`、`CSS`、`JS` 模組化架構的網頁版正體中文造字益智遊戲，收錄全 **110 階**（537 個基礎部件、1,365 個可合成正體漢字），並內建 **階段寶箱解鎖**、**金幣提示系統**、**VISA / Mastercard / JCB 信用卡儲值**，以及 **使用者登入與本機裝置即時暫存**。

## 專案檔案結構

```text
moyun-char-game/
├── index.html          # 主畫面結構與五大互動視窗（寶箱、金幣商城、帳號中心、偏旁圖鑑、110 階總覽）
├── css/
│   └── style.css       # 宋代活字印刷與宣紙美學樣式、寶箱開啟動畫、信用卡即時卡面視覺
├── js/
│   ├── data.js         # 全 110 階造字資料庫、雙子星異構字（如 杏/呆、加/另、旱/旰）與偏旁變形規則
│   ├── storage.js      # 雙層進度引擎：本機裝置即時暫存 (localStorage) + 多帳號登入切換 + JSON 匯出/匯入
│   ├── payment.js      # 金幣儲值方案與 VISA / Mastercard / JCB 卡別自動辨識及 Luhn 演算法檢核
│   └── app.js          # 核心合成台控制器、階段寶箱解鎖流程、三階金幣錦囊與 Web Audio 音效
└── README.md           # 專案說明與雲端/金流串接指南
```

## 核心功能亮點

1. **階段寶箱解鎖機制 (`階段寶箱`)**
   - 每階達成指定造字目標數量後，頂部「下階傳承寶箱」按鈕會亮起金光。
   - 點擊開啟寶箱動畫，即可獲得 **下一階的 5 個全新活字部件** 與 **階段金幣獎勵**。
2. **雙層進度保存（使用者登入 + 裝置即時暫存）**
   - 每次合成新字、花費金幣或開啟寶箱，系統都會自動寫入裝置 `localStorage` 暫存。
   - 點擊上方「訪客（本機暫存）」可註冊或登入使用者帳號，將目前進度綁定至個人存檔並支援多帳號一鍵切換，亦可下載 `.json` 進度備份檔。
   - 若部署至線上伺服器，可在 `js/storage.js` 的 `CloudSyncAdapter.endpoint` 填入您的後端 API 端點啟用雲端同步。
3. **金幣制度與三階字理錦囊**
   - 造出新字（+10 金幣）、發現雙子星異構字（+15 金幣）與開啟寶箱皆可免費賺取金幣。
   - 遇瓶頸時可花費金幣購買三種提示：**字義暗示 (15 🪙)**、**結構與首部 (30 🪙)**、**揭示完整配方 (60 🪙)**。
4. **信用卡儲值金幣（支援 VISA / Mastercard / JCB）**
   - 點擊右上角「+ 儲值」開啟錢莊視窗，輸入卡號時會自動偵測 **VISA (`4...`)**、**Mastercard (`51-55` / `2221-2720`)**、**JCB (`3528-3589`)** 並切換卡面樣式與執行 Luhn 檢核。
   - 內建一鍵填入測試卡號按鈕方便單機測試；正式上線時可於 `js/payment.js` 的 `processCardPayment` 串接 Stripe / TapPay / 綠界 ECPay 金流 API。
